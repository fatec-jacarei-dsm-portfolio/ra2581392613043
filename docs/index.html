Desenvolvimento de Software Multiplataforma  ·  Geotecnologias

Sou tecnóloga em Geoprocessamento e atuo com sensoriamento remoto, cartografia e análise espacial. Hoje curso Desenvolvimento de Software Multiplataforma na Fatec Jacareí para unir dados geográficos e desenvolvimento de sistemas — construindo soluções que transformam imagens de satélite e dados territoriais em informação útil.

01 Objetivos e áreas de interesse

Geotecnologia + Software

Desenvolver aplicações web e desktop que consumam, processem e apresentem dados geoespaciais — de APIs de imagens de satélite a mapas interativos.

Dados e classificação

Aplicar aprendizado de máquina à classificação de uso e cobertura da terra, detecção de desmatamento e de cicatrizes de incêndio.

Back-end e banco de dados

Aprofundar em modelagem de dados, SQL e integração de bancos espaciais (PostgreSQL/PostGIS) com aplicações multiplataforma.
